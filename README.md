## 🚀 Возможности
*   **Умная память:** Автосуммаризация диалогов и сохранение важных фактов о пользователе.
*   **Инструменты:** Чтение/запись файлов, выполнение команд в терминале, поиск в интернете.
*   **ИИ-ядро:** Работает на базе DeepSeek API.
*   **Веб-интерфейс:** Простой чат для общения (index.html).

## 🛠️ Как запустить

2. Скачайте этот репозиторий.
3. В папке проекта создайте файл `.env` и добавьте туда свой ключ:
